API эндпоинты

Основные API для работы с системой:

  • POST /api/chat — чат с LLM ассистентом
  • POST /api/documents/generate — генерация документа из шаблона
  • POST /api/cases/{id}/export-zip — экспорт кейса в ZIP
  • GET /api/cases/{id}/pricing — расчёт НМЦ и валидация
  • POST /api/cases/{id}/candidates — добавление кандидата
  • POST /api/cases/{id}/offers — добавление коммерческого предложения
